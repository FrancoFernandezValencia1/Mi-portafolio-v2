Simulador de Algoritmos

Herramienta Interactiva de Visualización de Estructuras de Datos y Ordenamiento

Descripción General

El Simulador de Algoritmos es una aplicación interactiva diseñada con fines educativos para facilitar la comprensión de estructuras de datos y algoritmos clásicos de ordenamiento y búsqueda (Burbuja, Quicksort, Búsqueda Binaria, etc.). Permite observar paso a paso la ejecución lógica de cada procedimiento mediante animaciones y métricas en tiempo real.

Características Principales

  • Visualización paso a paso con controles de reproducción (Iniciar, Pausar, Reiniciar).
  • Ajuste interactivo de la velocidad de simulación y el tamaño de los datos de entrada.
  • Comparativa de algoritmos en función del número de iteraciones, comparaciones e intercambios.
  • Resaltado de código y variables en tiempo de ejecución.
  • Generación aleatoria de conjuntos de datos y opciones de personalización manual.

Tecnologías Utilizadas

Lenguajes & Visualización: JavaScript (ES6+), HTML5 Canvas / CSS Animations.
Estilos & Layout: Bootstrap 5, FontAwesome.
Control de Versiones: Git & GitHub.
