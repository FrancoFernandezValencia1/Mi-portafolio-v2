Sistema de Inventario

Proyecto de Desarrollo Web & Bases de Datos

Descripción General

Este sistema permite la gestión integral de inventarios para pequeñas y medianas empresas. Facilita el registro de productos, control de stock en tiempo real, alertas de desabastecimiento y generación de reportes detallados de entradas y salidas.

Características Principales

  • Autenticación de usuarios con roles (Administrador y Operador).
  • Módulo CRUD completo para gestión de productos y categorías.
  • Generación de reportes exportables a PDF y Excel.
  • Interfaz responsive adaptada a dispositivos móviles y tablets.

Tecnologías Utilizadas

Frontend: HTML5, CSS3, Bootstrap 5, JavaScript.
Backend: Python (Flask / Django) o Java.
Base de Datos: PostgreSQL / MySQL.
