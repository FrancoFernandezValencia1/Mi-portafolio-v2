Sistema Kaypi

Plataforma Web de Gestión para Restaurantes, Caja y Cocina

Descripción General

Kaypi es un sistema web integral diseñado para la automatización y gestión operativa de restaurantes. La plataforma permite administrar comandas por mesas, supervisar los pedidos en tiempo real en el área de cocina y gestionar la facturación e impresión de boletas de consumo en caja de forma rápida, fluida y segura.

Características Principales

  • Gestión y monitoreo de mesas y comandas en tiempo real.
  • Módulo de Caja automatizado para el cobro, liberación de mesas y emisión de tickets.
  • Formato de boletas adaptable y optimizado para impresión térmica (`@media print`).
  • Control de acceso basado en roles (Administrador, Cajero, Mesero, Cocina).
  • Estructura HTML5 semántica y accesible bajo estrictos estándares de la W3C.
  • Blindaje y validación en la extracción dinámica de datos JSON (`cart_data`).

Tecnologías Utilizadas

Backend: PHP 8+, Laravel Framework, Blade Templating Engine.
Frontend & UI: HTML5 Semántico (W3C), Tailwind CSS, Custom CSS3, FontAwesome 6.
Interactividad: Alpine.js, JavaScript ES6+ / Fetch API (AJAX).
Calidad & Control: Validación W3C, Análisis estático con SonarQube, Git & GitHub.
