Dashboard de Clima

Aplicación Web de Monitoreo Meteorológico en Tiempo Real

Descripción General

El Dashboard de Clima es una plataforma interactiva que consulta servicios API en tiempo real para mostrar información meteorológica detallada de cualquier ciudad del mundo. Ofrece una visualización clara del estado actual del tiempo, pronósticos para los próximos días y métricas atmosféricas clave mediante componentes gráficos atractivos.

Características Principales

  • Búsqueda global de ciudades con sugerencias de geolocalización.
  • Visualización de condiciones en tiempo real (temperatura, humedad, velocidad del viento, presión atmosférica).
  • Pronóstico meteorológico extendido (5 días / 3 horas).
  • Cambio dinámico de fondos o iconos según el clima (soleado, lluvioso, nublado, etc.).
  • Manejo asíncrono de peticiones mediante Promises y Fetch API.

Tecnologías Utilizadas

Frontend: HTML5, CSS3, JavaScript (Async/Await, Fetch API).
API Integrada: OpenWeatherMap API / WeatherAPI.
Estilos & Componentes: Bootstrap 5, FontAwesome.
Control de Versiones: Git & GitHub.
